# REDESIGN_PLAN.md

План приведения фронтенда Altai Dynamics к утверждённой дизайн-системе (MASTER_DESIGN_SPEC v1.0).
Аудит: docs/FRONTEND_INVENTORY.md.

## 1. Ключевые решения

1. **Два фронтенда, одна система токенов.** Корпоративный сайт остаётся в статической папке `landing/` (altaidynamics.kz), приложение — Next.js (pulse.altaidynamics.kz). Токены — CSS custom properties в обоих; в приложении дополнительно маппинг в tailwind.config.ts. Стек не меняется: замена статики на Next-роуты потребовала бы изменения деплоя и переписывания middleware-гейтов, что запрещено без разрешения владельца.
2. **Палитра Architectural Mono** (#111111, #292929, #F2F0EB, #B2F230, #858585) заменяет синюю палитру. Корпоративный сайт — преимущественно тёмный с редакционными светлыми секциями. Приложение (продукт) — полная светлая и тёмная тема, выбор сохраняется, по умолчанию системная (переход с текущего «light по умолчанию» выполняется кодом темы без потери сохранённого выбора).
3. **Радиусы:** корпоративный сайт 0 px; приложение 4 px (кнопки, карточки, поля, панели), модальные окна 6 px; исключения — аватары и индикаторы.
4. **Шрифты self-hosted (WOFF2):** Inter (интерфейс), JetBrains Mono (технические метки), Bodoni Moda + Playfair Display (редакционные заголовки; Playfair — кириллический editorial). Перед подключением проверяется покрытие казахских букв Ә Ғ Қ Ң Ө Ұ Ү Һ І (fontTools); непокрытые начертания заменяются документированным fallback. Лицензии: OFL (все четыре семейства). Файлы кладутся в landing/assets/fonts/ и app/fonts/ с subsetting на latin + cyrillic(-ext).
5. **Altai Field:** предрассчитанные контуры — Node-скрипт `scripts/gen-altai-field.mjs` (фиксированный seed, модуль simplex-noise уже в зависимостях приложения; для скрипта отдельная лёгкая реализация или та же зависимость) → оптимизированный SVG для LOD 0/1/2 + JSON вершин. На странице: статический SVG (Core), Canvas-слой с упрощённой геометрией (Lite), детальная геометрия (High), трансформации (Ultra). Контроллер качества в landing/assets/motion.js: старт с Lite, замер кадрового интервала, понижение при перегрузке, повышение после стабильных 10 с, cooldown 10 с, откат в Core при ошибках; prefers-reduced-motion и скрытая вкладка → статический SVG, циклы остановлены.
6. **i18n:** словари en/ru/kk в `landing/assets/i18n.js` (данные, не Google Translate), пути `/` (ru), `/en/`, `/kk/` с hreflang и корректным lang. RTL-совместимость на уровне структуры (логические CSS-свойства), словарь RTL-языка добавляется без переработки компонентов.
7. **Разделы сайта:** публикуются только с реальным контентом. Home, Products (AD Pulse, цены по PLAN_PRODAZH_AD_PULSE.md §7.1 в ₸), Contact (форма → существующий POST https://pulse.altaidynamics.kz/api/support/public). Company/Technology/Industries/Insights/Careers/Partners & Investors — каркас готовится, в публичную навигацию и sitemap не попадают до контента владельца.
8. **Логотип:** финальная форма не утверждена — используется текстовый wordmark «Altai Dynamics»; существующие файлы знаков (landing/logo.svg, logo-altai.png, app logo) не удаляются и не заменяются.
9. **Motion:** токены по спецификации (100/150/200/250–350/500–700/1200–2000 мс, easing из §13.2) в одном файле `landing/assets/motion.js`; в приложении — только функциональные микровзаимодействия, без декоративных циклов в рабочих интерфейсах.
10. **Без изменений:** backend-контракты, API-маршруты, схема БД, middleware-логика авторизации, деплой-конфигурация, функциональность страниц.

## 2. Фазы

| Фаза | Работы | Критерий приёмки |
|---|---|---|
| 0 | Аудит, базовая сборка | готово: инвентаризация, build exit 0 |
| 1 | План | этот документ |
| 2 | Токены, шрифты, темы (landing + app) | оба фронта собираются; палитра/радиусы/шрифты по спецификации; выбор темы сохраняется |
| 3 | Altai Field: генератор, SVG fallback, LOD | скрипт воспроизводим; SVG открывается без JS; Core-режим полный |
| 4 | Оболочка сайта: header, footer, мобильная навигация, i18n, a11y (skip-link, focus, контраст) | клавиатурная навигация, reduced-motion, en/ru/kk без Google Translate |
| 5 | Страницы: index (+ /en /kk), 404, правовые, docs, support в новом стиле | контент реальный, формы рабочие, hreflang, sitemap без пустых разделов |
| 6 | Motion engine + адаптивное качество | профили переключаются по замерам; reduced-motion без потери контента |
| 7 | Интеграция форм с существующим API | отправка проходит через /api/support/public, состояния loading/success/error, защита от повторной отправки |
| 8 | Рестайлинг приложения: токены → оболочка → auth-страницы → кабинет → админка → onboarding | 100% страниц из инвентаризации в новой ДС; функциональность не тронута |
| 9 | Валидация: build, lint, unit, smoke, visual, Lighthouse | результаты задокументированы в QA_REPORT.md; PASS только проверенные |
| 10 | Коррекция дефектов, повторный аудит, финальный отчёт | дефекты закрыты или задокументированы; инвентаризация сверена повторно |

## 3. Файлы

Новые: landing/assets/tokens.css, landing/assets/fonts/*, landing/assets/field.js, landing/assets/motion.js, landing/assets/i18n.js, landing/en/*, landing/kk/*, scripts/gen-altai-field.mjs, docs/{DESIGN,BRAND,MOTION,PERFORMANCE,FRONTEND_ARCHITECTURE,QA_REPORT}.md.
Изменяемые: landing/*.html, landing/assets/styles.css, landing/assets/app.js, app/globals.css, tailwind.config.ts, app/layout.tsx, компоненты и страницы по мере фазы 8.
Неприкосновенные: supabase/migrations, API-маршруты, lib/** (логика), whatsapp-gateway, vercel.json, middleware-логика авторизации.

## 4. Риски

1. **Казахское покрытие шрифтов** — проверяется fontTools до подключения; fallback документируется в DESIGN.md.
2. **Визуальные регрессии приложения** — визуальные тесты Playwright как регресс-сеть; эталоны обновляются осознанно (test:visual:update) только после приёмки конкретной страницы.
3. **Объём** — инвентаризация как единственный источник истины; статусы обновляются по мере фаз; непроверенное помечается NOT TESTED, а не PASS.
4. **Удаление Google Translate** — покрытие языков сокращается до en/ru/kk, что соответствует спецификации (§19).
5. **Нечистое рабочее дерево** — правки вносятся поверх существующих изменений landing/, без коммитов и без force-операций.
