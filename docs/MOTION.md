# MOTION.md — AD Motion Engine

## Токены движения (§13.2)

В `landing/assets/tokens.css`: instant 100 мс, fast 150 мс, standard 200 мс, page 300 мс, editorial reveal 600 мс, Altai Field 1600 мс (зарезервировано). Easing: standard `cubic-bezier(0.2,0,0,1)`, enter `(0,0,0.2,1)`, exit `(0.4,0,1,1)`. В приложении (`app/globals.css`): `--dur-fast: 150ms`, `--dur-base: 200ms`, `--ease`/`--ease-out` по спецификации.

## Профили отрисовки (§14.2)

- CORE: статический SVG в разметке (работает без JS), compositor-friendly анимации, никаких циклов.
- LITE: Canvas 2D с lite.json, DPR ≤1, без эффектов.
- HIGH: Canvas 2D с high.json, DPR ≤1.5.
- ULTRA: high.json + медленный transform-дрейф (CSS keyframes 90 с, только compositor), DPR ≤2.
WebGL не используется: контуры — векторные штрихи, Canvas 2D закрывает задачу без GPU-рисков (§14.6 «если необходимо»).

## Контроллер качества (§14.3)

`landing/assets/motion.js`. Старт с Lite (не Core: Core — только fallback по условиям). Окно измерения 3 с, метрика — p95 кадрового интервала: >22 мс — перегрузка (понижение после 3 окон подряд), >40 мс — мгновенное понижение, <18 мс — стабильность (повышение после 3 окон и cooldown 10 с). Core — терминальное состояние после ошибок. Учитываются: prefers-reduced-motion, Save-Data, поддержка Canvas 2D, DPR, размер области, видимость вкладки (Page Visibility), видимость поля (IntersectionObserver), ошибки загрузки геометрии. User-Agent и fingerprinting не используются. Понижение не вызывает layout shift (только скрытие canvas поверх SVG).

Проверено программно (Playwright, синтетические кадры 16 мс): LITE→HIGH→ULTRA с cooldown; скрытие вкладки/выход из viewport останавливают цикл; reduced motion → Core.

## Reduced motion (§16)

`prefers-reduced-motion: reduce` → профиль Core: статический SVG, никаких canvas-циклов и reveal-анимаций; длительности в tokens.css схлопываются до 1 мс. Контент полный — это не «сломанная» версия.

## Редакционные появления

`[data-reveal]`-элементы скрываются только после того, как JS добавил класс `js-anim` на `<html>` — без JS контент виден сразу. Появление — opacity+translateY (600 мс), один раз при входе в viewport.

## Жизненный цикл ресурсов (§14.8)

Вне viewport / скрытая вкладка — rAF остановлен; возврат — возобновление без скачка (сброс окна измерения); при ошибках — canvas скрыт, цикл остановлен, Core-представление остаётся.

## Ограничения

- Постоянный рендер-цикл есть только в активных профилях (Lite+); каждые 3 с выполняется сортировка окна кадров (≤600 элементов) — незначимая нагрузка.
- Калибровка порогов (22/18 мс, 3 окна, 10 с) — инженерные стартовые значения по §14.3; полевой калибровки ещё не было (нет трафика).
