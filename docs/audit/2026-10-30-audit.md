3. **Процесс разработки** — ветки staging, описанной в AGENTS.md, не существует; e2e-тесты
   есть, но в CI не запускаются; всё уходит сразу в прод.

### Горизонт 3 — «Продукт» (квартал)

Функциональные направления, по убыванию ценности для клиента:

1. **Оффлайн-режим для склада.** PWA уже есть, но без кэша данных. Кладовщик в цеху без
   связи должен иметь возможность записать расход, а синхронизация — догнать позже.
2. **Быстрые операции.** Сканирование QR/штрихкода материала, шаблоны частых движений,
   копирование прошлой операции — это то, что делают по 50 раз в день.
3. **Надёжность WhatsApp.** Очередь с повторами при сбое парсинга, отдельный экран «не
   распознано», обучение парсера на исправлениях пользователя.
4. **Аналитика для владельца.** Не только отчёты по материалам, но и динамика расхода,
   прогноз закупок по норме и остатку.
5. **Мультисклад и цеха.** Сейчас склад один на компанию; для производства с несколькими
   площадками это упрётся в стену быстро.

## 6. Критерии готовности и метрики

- **Definition of Done для задачи:** типы, линт, юнит-тесты зелёные; для UI — проверено на
  375 px; для серверных действий — проверка роли и `company_id`; для внешних вызовов — таймаут.
- **Метрики, которые стоит снимать:** время ответа p95 по дашборду и транзакциям; доля
  ошибок 5xx; число необработанных сообщений WhatsApp; время от заявки до первой операции
  у нового клиента.
- **Целевые пороги на квартал:** p95 < 800 мс, 5xx < 0.5%, необработанных сообщений — 0
  старше суток.

## 7. Что не проверено и требует доступа

1. **RLS на живой базе.** Политики прочитаны в миграциях и покрывают все таблицы, но
   поведение под реальными JWT разных ролей не проверялось. Нужен прогон: для каждой роли
   попытаться прочитать чужую компанию и записать в неё.
2. **Планы запросов.** Индексы в миграциях есть, но `EXPLAIN` на реальных объёмах не снимался.
3. **Состояние миграций в базе.** Применены ли 049–053 и совпадает ли схема с репозиторием —
   проверяется только подключением.
4. **Внешние интеграции.** Реальная доставка Wazzup и Telegram проверялись вручную; в
   автоматике их нет.
5. **Визуальные снимки** не перегенерированы под React 19.
