Договор обработки данных (DPA)

Версия 1.0 · 26 ноября 2026

Документ определяет, как Altai Dynamics обрабатывает данные клиента в AD Pulse. Он действует вместе с политикой конфиденциальности.

1. Роли

Клиент — контроллер производственных записей и данных сотрудников. Altai Dynamics — обработчик: обрабатывает данные по поручению клиента и для работы сервиса. По коммерческим записям (счета, переписка) Altai Dynamics — контроллер.

2. Предмет и срок

Обработка длится, пока активен аккаунт, и 30 дней после его закрытия для удаления. Категории данных и цели перечислены в политике конфиденциальности.

3. Обязанности обработчика

  • обрабатывать данные только по поручению и для сервиса;
  • ограничивать доступ сотрудников необходимостью;
  • применять меры защиты из раздела 4;
  • уведомлять клиента об инциденте без неоправданной задержки;
  • помогать с запросами субъектов данных и удалением;
  • по окончании — удалить или вернуть данные по указанию клиента.

4. Меры защиты

HTTPS, Row Level Security по company_id, четыре роли, аудит изменений, хранение секретов в переменных окружения, шифрование данных у хостинг-провайдеров. Прикладного шифрования записей сверх этого нет.

6. Передача за пределы ЕС

База в ЕС. Передача вне ЕС идёт только к поставщикам из таблицы, каждый применяет свой механизм передачи в стандартных условиях.

7. Инциденты

При инциденте уведомляем клиента без неоправданной задержки, описываем характер, затронутые данные и принятые меры.

8. Аудит

Сертификатов ISO 27001 и SOC 2 нет, внешнего аудита не было. Отвечаем на письменные опросы безопасности и проводим звонок с технической командой.

9. Удаление и возврат

По письменному запросу администратора удаляем данные и выдаём подтверждение. Выгрузка доступна в Excel до удаления.
